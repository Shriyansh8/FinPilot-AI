# 💰 FinPilot AI

> Smart Finance Companion powered by AI

FinPilot AI is a full-stack AI-powered personal finance management application that helps users track expenses, analyze spending habits, generate financial insights, and receive personalized AI recommendations for better money management.

Built with **React**, **Flask**, **SQLite**, **Chart.js**, and **Groq AI**, the application provides an intuitive dashboard with real-time analytics and intelligent financial suggestions.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Shriyansh8/FinPilot-AI.git
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

## Backend

```bash
cd backend

pip install -r requirements.txt

python app.py
```
